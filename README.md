This is an analysis of a Shopify e-commerce website.

The objective of  this analysis is to identify winning and underperforming products

I analysed the following: 

1. Revenue by product
2. Conversion rate per product
3. Price vs sales relationship
4. Inventory turnover

The final reports generated are 

1. Product ranking dashboard
2. Segmentation (Top / Average / Poor performers)
3. Clear business actions


Tech Stack: Power BI and Visual Studio
